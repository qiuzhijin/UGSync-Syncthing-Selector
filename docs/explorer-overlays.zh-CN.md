# Windows 资源管理器同步角标

适用 Windows x64。2026-11-14 已在本机核验 Explorer 加载扩展、状态缓存及蓝/绿/红系统槽位；已修正槽位排序，采用左下角约 14×14 的透明画布小标记。其他电脑仍需按下述步骤安装验收。

首版只支持本地磁盘路径，不为 UNC 网络路径或重解析点提供角标，以避免资源管理器查询阻塞。

## 颜色

| 颜色 | 含义 |
| --- | --- |
| 蓝色 | 已查询的文件仍待同步，或磁盘内容已变化尚未确认；文件夹所在任务尚未完全收敛 |
| 绿色 | 文件磁盘大小/时间与引擎记录匹配，版本等于全局版本，所有共享对端在线且均持有完整副本；文件夹仅在整个任务完成时显示绿色 |
| 红色 | 本地仍存在但已取消选择的文件或文件夹、引擎标记的忽略项、已识别项目所属任务暂停，或通过客户端明确退出并停止引擎 |
| 无角标 | 未知/离线/缓存失效/还没完成查询，不表示已同步 |

首版文件夹判断保守：所在任务尚未整体完成时，某个已经完成的子文件夹仍可能显示蓝色。不是按文件夹存在就判断绿色。

## 安装

1. 退出旧客户端，完整解压最新部署包。
2. 用管理员身份打开 **64 位 PowerShell**，进入解压目录。
3. 运行 `ExplorerExtension/install_overlays.ps1 -Action Install`，注册三个独立角标处理器。
4. 启动 `UGSync-Syncthing-Selector.exe`，连接本机后勾选“资源管理器同步角标（需先安装 Explorer 扩展）”。
5. 保存其他工作后注销并重新登录 Windows，让 Explorer 重新加载扩展；程序不会自动结束 Explorer 或注销会话。
6. 打开同步目录，等候后台查询；必要时按 F5 刷新。首次查询前可能无角标。

脚本可先加 `-WhatIf` 预览，不注册、不复制。实际安装会校验随包文件摘要，复制 DLL/图标至 Program Files 的独立版本目录，写入本扩展自己的 COM 和角标注册项。预览包未签名，摘要校验不替代发布者身份认证。

Windows 角标槽位有限，已有同步软件可能占用；不能保证三个颜色在所有机器上同时显示。安装不会删除、重命名或禁用其他软件角标。标准角标位置由 Windows 决定，通常在图标左下角，客户端不能保证右下角位置。

## 工作方式

原生 DLL 不加载 Python、不访问网络、不扫描文件内容。它读取当前用户 `%LOCALAPPDATA%/UGSync/overlays` 中的短状态记录；未缓存项目通过本地请求文件提交后台查询。只为已公布的 Syncthing 根目录提交请求，其他路径不参与。

客户端后台查询 Syncthing，仅读取文件属性和引擎记录，不修改业务文件或同步规则。蓝/绿状态缓存 20 秒；后台故障会清空已知角标并请求刷新，不持续冒充绿色。强制结束客户端后可能需 F5 或重新打开目录让 Explorer 重查；明确退出会先写红色。

每轮优先处理最多 32 个新查询，再轮询已知项目；最多跟踪 1024 个路径、16 个根目录。超出范围、特殊忽略规则、离线或尚未进入本地索引的项目可能没有角标。首次在暂停状态启动时，尚未识别的项目也不凭路径猜测红色。当前不提供云占位下载。

缓存和请求里含本机路径，应视为私人运行数据，不上传公开仓库。

## 验收

安装后先检查一个专用测试目录：

- 正在同步时出现蓝色；双方完成且后台确认后出现绿色。
- 修改已完成文件，刷新后不能继续误报旧版绿色。
- 暂停任务，已识别项目转红；恢复后重新查询。
- 明确退出客户端后显示红色，重新启动并启用后重新获取状态。
- 排除目录不出现绿色；非同步目录没有角标。
- 文件夹大批量打开、复制、重命名不应因扩展发生明显卡顿。

## 卸载

先取消客户端角标开关，再在管理员 PowerShell 运行：

```powershell
.\ExplorerExtension\install_overlays.ps1 -Action Uninstall
```

脚本仅移除自身三个角标项和对应 COM 类，不删除其他软件项，不清理业务数据。因 Explorer 可能仍加载 DLL，Program Files 文件保留；注销重新登录后可另行核对清理自己的 `UGSyncShell` 安装文件。

注册依据：[Microsoft 角标处理器注册](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-register-icon-overlay-handlers)、[IShellIconOverlayIdentifier 接口](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nn-shlobj_core-ishelliconoverlayidentifier)。
